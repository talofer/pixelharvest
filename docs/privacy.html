PixelHarvest Privacy Policy

Effective Date: November 2026 • Manifest V3 Zero-Backend Architecture

1. 100% Client-Side, In-Memory Processing

PixelHarvest operates strictly inside your local browser memory (RAM). All DOM asset discovery (<img>, <picture>, CSS background-image, and inline <svg>), HTML5 Canvas image transcoding (WebP/AVIF to JPG/PNG), and ZIP archiving via JSZip happen locally on your device. Your images, browsing history, and page URLs are never uploaded, stored, or transmitted to any remote server.

2. Minimal Chrome Manifest V3 Permissions

  • activeTab: Grants temporary, on-demand access to inspect the currently open tab only when you explicitly click the PixelHarvest toolbar button. PixelHarvest never requests <all_urls> host permissions.
  • downloads: Used solely to save your selected images or bundled .zip archive directly to your computer's local Downloads folder.
  • storage: Uses chrome.storage.local strictly to store local UI preferences and anonymous pricing survey state on your device.

3. Zero-PII Anonymous Telemetry

When a batch selection exceeds the 25-image free threshold, PixelHarvest displays an optional pricing feedback prompt and sends a fire-and-forget anonymous counter event (containing only numerical asset count, variant number, button choice, target format, and timestamp). It never includes page URLs, domain names, IP-identifying metadata, or image contents.
